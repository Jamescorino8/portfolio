# Index Page Suggestions

## High Value, Low Effort

### 1. Fill in the about items more
Add 1–2 lines that signal personality or direction — what you're interested in, what kind of engineer you want to be.

Examples:
- `interested in systems, compilers, and the web.`
- `i like building things that are fast and close to the metal.`

### 2. Graduation year
Recruiters need to know when you're available. Add to the existing line:
- `studies cs @ ualbany, class of '27.`

### 3. Link to builds from this page
Add a subtle line at the bottom of the about section linking to `/builds` so visitors have a clear next step.

Example: `→ see what i've built`

---

## Worth Considering

### 4. A "currently" line
One line about what you're actively working on or learning right now. Update every few months.

Examples:
- `currently: building a travel planner in react + typescript.`
- `currently: reading about distributed systems.`

### 5. Location / timezone
Useful for international recruiters, especially relevant with the SKKU internship.

Example: `albany, ny / est`
